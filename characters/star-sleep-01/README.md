# 星眠 / Star Sleep

全新 Coopanion 桌宠角色工程。**不继承 GPT 龙娘的母版、坐标、素材或角色 ID。**

## 当前状态

- 角色 ID：`star-sleep-01`
- 预览版本：`0.1.0`
- 母版：1086×1448 RGBA，用户提供的透明立绘
- 当前视觉交付：完整立绘单图预览包
- 当前工程阶段：母版已锁定；多层美术与独立动作待补绘

完整立绘只有一个合并图层。为避免破坏原画，不用矩形裁切伪造头发、眼睛、手臂、腿或裙摆层，也不宣称当前已经具有独立招手、眨眼、表情替换和坐姿动画。

## 文件

- `production-lock.json`：母版 SHA-256、画布与几何锚点
- `spec.json`：角色独立坐标、点击区、锚点及当前单图图层契约
- `DESIGN_BRIEF.md`：造型基线、下一阶段分件目标与验收边界

原画二进制与可安装预览 ZIP 随本次交付的 `star-sleep-source-0.1.0.zip` 提供。将其中 `characters/star-sleep-01/art-source/master.png` 和 `packs/star-sleep-01-v001/` 解压到仓库同名路径，即可还原完整源工程。
