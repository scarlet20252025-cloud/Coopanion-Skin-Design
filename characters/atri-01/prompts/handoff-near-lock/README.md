# 交给网页版 ChatGPT「工作」的一条任务：近侧马尾（一件）

网页版读不到本机路径，所以这里把这次要用的东西全部放在同一个目录里，只认**本目录**：

```
characters/atri-01/prompts/handoff-near-lock/
  00-一条消息-直接发送.md            <<< 这份整篇就是要发的那条消息，直接复制粘贴
  01-master-full-canvas.png          完整原图（1145×1374 透明底）
  02-near-lock-region-magenta.png    同一张图，近侧马尾所在区域用品红方带标出
  03-prompt-to-paste.txt             正文，整段粘贴
  LATEST-WORKING-NOTES.md            当前最新结论（优先于仓库里任何旧失败记录）
```

**我们和网页版暂时不能直接沟通**，所以发出去的东西必须自洽：`00-一条消息-直接发送.md`
已经写成一份独立可读的交接文件（含任务、附件说明、硬性要求、自检项、已失败做法、交付格式），
整篇复制即可，不需要任何补充说明。`03-prompt-to-paste.txt` 是早期简版，发 `00` 就够。

## 发之前

1. 新开一个 ChatGPT 会话，切到「工作」模式，推理强度选「高」（不需要 MAX）。
2. 附件只加这两个：`01-master-full-canvas.png`、`02-near-lock-region-magenta.png`。
3. 把 `03-prompt-to-paste.txt` 的正文整段粘贴进去，**一条发完，不要在同一个会话里追问**；
   不合格就把问题写进新提示词、另开会话再发。

## 要它交什么

只交**一件**：被脸旁那个黑色蝴蝶结系住、单独垂在头发最外缘的那根窄马尾，画完整（包括在原图里
被别的头发挡住的部分），其余全部透明；画布尺寸与原图一致。

## 收件（交给操作员/协作 AI 时按这几条报）

1. 尺寸 1145×1374，与 `01-master-full-canvas.png` 同坐标，叠回去看。
2. 品红底和黑底各看一遍边缘：平直截边、台阶、半透明切口、混色都不收。
3. alpha>0 的连通块必须是 **1**（别用 alpha>8 去裁框看，会把散落碎块藏掉）。
4. 数孤立深色虚点和低 alpha 杂点。
5. 单独看形状：是不是一根完整、自然、从蝴蝶结垂下来的马尾；内部线条与明暗要和原图同一套画法。
6. 放回全身，与母版并排看；抬手到最大角度看根部会不会露截口。

## 这一件为什么必须完整

它自己会摆动；角色抬手时，原来被别的头发挡住的段落会露出来。所以被挡住的地方也要画出来，
不能只描可见的剪影。

## 已经失败、不要再走的做法

- 同一件用单次 `images/edits` 接口连发三次：`ponytail-near-complete-09/10/11.png`，都把整片侧发
  当成这一件交回（alpha>0 连通块 228／158／575）。**单次调用复现不了「工作模式」**，别再走这条。
- 给模型画目标线、给轮廓坐标、描述形状：`prompts/image25-near-lock-v3.txt` 就是这么写的，交回
  的是一条细带。**不要再用这种提示词。**
- 我们自己动像素：用 P 图抠图当素材、用代码按母版形体或蝴蝶结遮罩删 alpha、用逐行横向变形去
  “对齐”。这三条都违反了约定的工作模式，已撤销，不要恢复。

## 收件后由我们做（只做这些）

测量、标注、配准（只允许小幅平移）、合成、打包，然后按上面的收件清单复验并更新记录。
