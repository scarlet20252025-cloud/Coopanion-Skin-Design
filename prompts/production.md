# 提示词模板

填写大括号字段后使用；未填的角色细节由设定阶段解决。本轮未执行任何生成。

## 母版

```text
用途：Coopanion 原创 Q 版人物的分件动画母版。
角色：{已确认的名字/性格/发型/服装/配色/辨识点}。
全身，基本直立，轻微侧身朝右，双眼可见，中立表情；四肢轮廓可分辨。
头身比 {已确认比例}，统一光源和线条风格。
背景真正透明，无场景、文字、地面投影；头发、鞋和配件完整留在画面内。
避免大幅透视、交叉遮挡的手臂和无法拆开的密集挂饰。
```

## 单部件拆分与补全

```text
输入 1 为唯一已验收母版，输入 2 为待修区域示意遮罩。
只处理 {部件与目标}，补全原本被 {遮挡物} 挡住的结构。
严格保留母版的比例、朝向、位置、线条粗细、颜色和光照。
不重新设计角色、不改变其他区域；不要把遮罩提示色画入结果。
输出保留完整画布与真实透明背景，便于对齐；不要重新居中或自动裁边。
```

生成结果仍需配准与遮罩合成；「保持其他部分不变」是目标，不是模型保证。

## 差分

```text
基于已验收母版，只把 {眼睛/嘴/下半身} 改为 {具体表情/坐姿}。
保持其余部件、脸型、发型、服装设计与全部颜色一致。
保持画布和目标部件的定位；结果用于替换既有分件而非重画全身。
```

## 记录

每次记录母版版本、输入路径与哈希、工具/模型（工具可提供时）、完整提示词、遮罩、输出、缺陷和结论。同一失败只修改一个变量后复试。
