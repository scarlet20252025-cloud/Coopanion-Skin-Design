# 黑金魔女 · Coopanion API 2 形象

制作署名 Asryto。工程、脚本、许可说明、源贴图与重建说明由 [Coopanion-Skin-Design](https://github.com/scarlet20252025-cloud/Coopanion-Skin-Design) 提供。

`effects.js` 的反应标记源自 Coopanion 鲸鱼形象，通过绘制适配器重新组织坐标及颜色。本代码依赖 Coopanion API 2 的官方宿主 kit。接入时使用的 [Coopanion 上游提交](https://github.com/Pal-AI-Lab/Coopanion/tree/91293b3e31b94397a8f2eb79dffec40f4c6d8817) 已记录。随包提供上游许可 [LICENSE](LICENSE)。
