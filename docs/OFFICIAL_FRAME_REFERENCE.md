# 官方鲸鱼娘动作参考库

参考版本固定为 Pal-AI-Lab / Coopanion `91293b3e31b94397a8f2eb79dffec40f4c6d8817`，服装/配色 `deepseek-maid`。源路径为 `packages/cortico-world-desktop-pet/web/whale` 与 `web/kit`。没有改动上游模型、贴图、行为公式和弹簧常数。

官方采用实时分件动画，并不存在一套能直接解包的有限原始帧序列。本工程运行官方代码，将有限时间窗口中的每一帧导出为 PNG；不能据此宣称涵盖任意输入和无限循环的全部可能状态。

本次实际导出 **48 项、14,880 张 PNG**：19 个表情、18 个动作、11 个交互补充。全部官方词表 ID 已覆盖，帧数与非空检查通过。详细清单见 `official-reference-manifest.json`。

## 采样与浏览

- 60 fps 固定步长；448×448 透明 PNG；身体比例 S=0.8。
- 每项重置身体、弹簧及随机种子 `20261013`，固定 1 秒预热。站起从坐姿开始。
- 全部 19 个表情、18 个动作；常规项 4.8 秒，犯困 6 秒，睡眠 8 秒。
- 补充待机眨眼、说话、倾听、工作、双向行走/跑步、拖拽释放、睡醒、视线跟随等交互参考。
- `0000.png` 对应指令后 1/60 秒。`timeline.json` 保存每帧时间、位置、朝向、模式、命中区等数据。
- `preview.webp` 为 30 fps 浏览副本，原始 PNG 没有删帧；`contact.png` 是 12 张关键帧摘要，不能代替完整帧序列。
- `tools-local/whale-reference-91293b3/index.html` 可逐帧拖动。官方图像仅在忽略目录用于本地参考，不进入龙娘形象包。

## 可复现入口

1. 启动 `node scripts/reference-server.mjs`，打开 `http://127.0.0.1:4320/`。
2. 页面上的导出按钮调用官方运行时，逐帧写入固定本地参考目录。先检查招手小样，再导出全部。
3. 运行 `.venv/Scripts/python scripts/build-reference-library.py` 验证帧数与非空图像，并建立浏览库。

参考服务器仅绑定本机；写入路由仅接受同源、固定目录、受限文件名的 PNG / 时间轴。大批原始帧不提交 Git。

## 已用于修正制作方法的观察

- 睡眠：坐姿下半身替换，搭配闭眼、低频呼吸和 Z 粒子。龙娘需要独立坐姿差分。
- 招手：手臂与头部有相对运动，不能把整幅角色摇摆当成招手。
- 跳跃：包含蓄力、腾空、落地、恢复；不能只上下平移几个循环帧。
- 点头/摇头：约 0.7 秒短动作；转圈约 0.6 秒；招手/鞠躬约 1.6 秒；舞蹈约 3.2 秒。动作后的回弹继续保留在采样窗口中。
- 五官和眨眼的几何来自官方母版。它们的机制可参考，坐标和闭眼曲线不能直接移植。

自动检查只证明导出文件完整、坐标有效和图像非空；并不代表逐帧人工验收，也不证明龙娘已实现对应动作。
