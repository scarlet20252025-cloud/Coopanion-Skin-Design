# Coopanion 桌宠工程通用手册

按这份指南能从选母版、拆件补画、定锚、绑定和做动作，一直做到预览、验收与交接。当前可完整重建的实例是[黑金魔女](制作与复现手册.md)。星眠 2.0.4、星云初版 0.1.3 和新版 0.1.9 用于复用已通过的做法，各自的画布、参数和层序只适用于对应画稿。[案例代码与工具索引](案例代码与工具索引.md)

## 1. 定母版与验收范围

- 先定角色、画风、比例、默认表情、道具、朝向和使用的宿主。四分之三朝右的短身 Q 版适合这一套 Coopanion 表现。站姿默认嘴合上，手和腿自然收拢，四肢落点清楚，耳尖到鞋底完整。坐下和睡觉另定构图。星眠可作为比例与线条参考，鲸鱼娘可作为可动站姿与动作参考。既有角色的识别特征仍以用户选定的母版为准。
- 选定后保存原图、朝右工作母版和哈希。需要镜像时先整体翻转，再标画面左、右与近、远。标锚用同一母版坐标，注明原点、y 轴方向、画布、地面，以及模型单位。星云初版为 **1139×1381**，新版 **1254×1254**，黑金魔女 **1163×1352**。PSD 以及不同画布尺寸的归档是参考，换图必须重新测量。
- 开工前列出要验收的静态状态、动作幅度和遮挡关系。可见轮廓、补画区域、允许接缝和必保留的像素分别标注。用户已有的腿、尾巴、正常脸和手工修件先锁定，得到同范围的授权后才改它们。

## 2. 拆件铁律与生图用法

1. **先拆出可见参考，再用生图补全。直接裁切只能做编辑输入或对照图，不能当成活动部件交付。** 同时补足活动件的隐藏端与移走它之后会露出的底层。肩膀、膝部、额头、发根、鬓发后衣领、压住的杖杆都要按动作范围留搭接。
2. 给模型清楚指定图片角色：残缺或完整工作图是编辑目标，母版是比例和颜色参考，标注图只说明缺口。保留稳定结构、轴线、局部保护区和足够透明留白。一次只修一个结构问题。若整条手臂被自动放大挪到中心、披肩重画成另一件衣服，先换输入设计和参考范围。在星眠，一次一处的完整画布编辑有足够稳定点做相减；在星云和魔女，已拆出的袖根、腿、脸可作局部补画目标，并以母版另作定位参考。
3. 保存真实的完整提示词、输入和未加工输出。提示词指定 RGBA 尺寸只是构图约束，生成后读实际尺寸和 alpha。有不透明底、轮廓串色或生成稿比例变化，按实测处理。固定画布不等于可见结构已对齐。
4. 裁幅和贴回分开记录。对稳定区先按关键点做相似变换或仿射；特征足够时可用 SIFT/RANSAC 粗配，再用 ECC 精调。每刀尽量回到母版复核。特征内点少、变换比例异常、只有一大块纯色、配准分高但五官或衣边明显偏移时，换锚点或退回供体。
5. 合并保护区的原像素和新补画。RGBA 重采样用预乘 alpha，避免半透明边混入衣色、肤色或旧背景。转回直通道后核对透明空白、多余连通域和原可见轮廓。导出全幅透明 PNG，运行时按 `box` 裁边。原位重组之后，每做几件再叠一次整身，并实际摆到最大和最小设计角度。

**判断顺序**：先问零位能否与母版叠回；再看关节能否在活动时保持连续；最后看画风、明暗、透视是否还是同一个角色。反复出现肩肘 Z 字、手过长、右臂缩水或膝盖错位时，回量肩、肘、腕、掌宽、鞋底与裙下髋点。补画按原轴生长，关节不能靠压扁、拉长或徒手搬位置补救。

## 3. 哪些像素归哪层

| 部位 | 处理与验证 |
| --- | --- |
| 身体和披肩 | 星云的披肩、裙摆、扣链归身体美术。臂独立，根部伸进披肩下。运行时先转手臂，再用固定于身体坐标的披肩前缘遮住根。遮罩只作用于臂，披肩仍有实体。比较母版肩边开始的交叠，双臂大幅摆时不能压到披肩外。 |
| 护肩和袖口 | 星云 v2 右臂的短铜色护肩整合到上臂，随臂动，保留腕饰与手完整；金圆扣仍归身体。星眠袖子、袖口和手也是一件。左右轮廓、手掌大小和透视分别以母版量。 |
| 裙与腿 | 需要运行层序时，从同一已确认身体切出固定后裙内衬。先画内衬，再画腿，最后画前裙；内衬与裙用同一身体变换。看摆腿时的裙缘、膝部接续和双鞋落地。裙形、褶皱和色调应对着母版，不凭另一张新生成裙替换。 |
| 脸、后发、前发 | 头先从身分出，再拆脸、前后发和五官。补刘海后的额头、后发的隐藏轮廓、发束背后的衣料。脸、五官、前后发绑定同一头部变换，后发小幅跟随效果要保证头部边界有足够搭接。转动出现两个头时找后发里残存的旧脸、旧外缘和父层变换。 |
| 胸前长发 | 星云白发两束跟头，保留自然弧线和连续纹理。发箍卡发根，发梢权重渐增并有迟滞。星云 v1 的长发前压扣子，母图中错误的一处压在扣子下面应纠正。拒收横条拼接、折线、掩掉发根或者把原长发改短的处理。 |
| 呆毛、耳朵 | 星云 v2 的呆毛独立补完整根，下面头皮同步补，`ahogeSeat` 压接缝。前后发共用耳朵网格和稳定边界，耳尖各从自身根部带动。星眠的羊耳另有独立层，位于兜帽上。按角色实际结构选层和权重。 |
| 小动物 | 星云 v1 的乌鸦先分离并用生图恢复完整形象，再绕真实爪点等比缩放、旋转和平移，不能为了塞回蒙版压扁它。蛇绕手臂时拆清前后圈，恢复蛇和发束遮住的上臂，深浅底检查边缘朦胧和杂色。 |
| 道具 | 星云 v1 握拳归臂，杖单独补拳后的轴，手必须像真正抓住杆。以握点核对手、杆前后，静止和摆臂都看。星云 v2 背杖独立，短一些、顺时针约 15°、稍往右下且杖首略降，尽量藏尾端；沿杆轴调整以保护杖头宝石形状。法杖最终位置读经用户手改的原位图。 |
| 尾巴 | 优先用用户已拆好的尾巴。星云 v2 尾巴在披肩重叠处靠前，尾根仍受裙侧遮挡。只分披肩的重叠区域为前后绘制层，重新复合检查 alpha 和颜色，尾巴不能无条件盖全身。 |

## 4. 表情必须先匹配母版

- 各表情保留各自配准的眼形、嘴形和需要时的眉形，不用同一开眼图压扁模拟犯困，不用临时 SVG 画闭眼。近远眼尺度不同，异色眼、眼角、眉、刘海遮挡和嘴的方向要分别贴合。嘟嘴与角色朝向一致，默认闭口，开心的嘴留轻巧。对拎起状态额外核对实际加载的图集帧，常规说话不能盖掉专用嘴。
- 开、半闭、全闭都以同一脸的母版匹配，在几何约束下做中间格和恢复。逐帧看，尤其眼褶残影、双睫毛、虹膜被挤扁和刘海前后的闪动。若旧做法只在睁闭两张之间硬切，替换整条动画链并在实际速度复验。
- **眼睛紧贴脸缘时，不能围着眼睛叠一圈肤色蒙版。** 黑金魔女用配准后的完整表情画稿，每格保留同一头部轮廓、脸颊、眉睫和前发遮挡关系。过渡贴回放在厚发区，眼下和嘴周不能留矩形接线。黑金魔女的检查对比旧接边所在皮肤与配准供体，并核对脸域外像素一致。
- 表情已认可而原脸有色差，先用相同坐标的中性脸颊采样建立共用色标，再调整默认脸。避开虹膜、唇、线稿、头发、阴影和腮红变化。黑金魔女两区取样由原脸约 `(251,227,223)` 对到 `(252,222,218)`，切换后还要看闭眼、说话、坐睡和还原待机。只修实际嘴形再生成开口格，检查半开格不会把下颌暗边拉到脸中。
- 眉毛优先做各侧连续干净图层，星云 v2 采用两条完整眉约 68% 透明压前发并做动态，不分段。刘海层底须去掉原残眉。若编辑目录里的正常脸没生效，先查加载的 revision、全幅 PNG 和最终裁图是否对应，再查编译注册是否改了轮廓。图集读不到时核对 RGBA、尺寸、行列、组数与索引是否同时更新。
- 生气、眩晕、冒汗、叹号、问号、倾听弧、爱心、泪滴和睡眠标记尽量复用官方宿主及形状并重设角色锚点。SVG 用于特效，眼嘴用绘制位图。检查双朝向、动作开始时出现及恢复后清理。
- 星眠式眩晕把宿主倾角送到颈部，依次经过坐下摇晃、圈眼转动与星星公转、闭眼短摇和回正。检查坐下后头部仍能运动，凳脚与腿稳定。若坐姿是整张画稿，用同一网格让颈口到身体区域的转动权重逐渐减小，避免切下头再叠出接缝。

## 5. 走路、跑步、倾听与方向

| 项目 | 工程判断与验收 |
| --- | --- |
| 走路速度 | 用户要求慢的是摆臂摆腿，宿主横移是另一条链。星云 v1/v2 的步态约 1.48 Hz，有约 0.27–0.28 秒起步。魔女按实际位移推进相位，每周期 120 母版像素，最高 1.75 周期/秒，腿错开半周期。两种做法都应测启动、稳态和收步。 |
| 承重与顺拐 | 魔女每条腿承重约 60%，离地回摆约 40%，按真实鞋底采样点校正接地。画面左臂与画面右腿同向，右臂与左腿同向，同侧手脚相反。两侧分别采前后极值，用实际绘制矩阵检查。两条腿交替、脚没穿地或切换了朝向，都不能代替手脚相位的断言。魔女的故障正是臂数组左/右和腿绘制右/左索引错配。 |
| 跑步 | 参考星眠低收手并用独立快步相。星云 v2 近远臂稳态约 16°/14°，用弹簧进入和退出，取消交替摆臂。脚端计算接地高度，有起跑、蹬地和短腾空。验收手不举到肩线，跑步和快移的站姿能区分。 |
| 头部三轴与倾听 | 横移或翻面属宿主，局部 yaw、pitch、roll 分别表示转头、抬低头与侧倾。星云 v2 倾听的 `roll` 表情目标约 −9.5°，用平滑插值经颈轴作用到头部。普通站立和倾听的 `groupTilt` 回零；拿起、飞行等模式按姿态另算。魔女实测头歪约 6.5° 且舞台和躯干旋转 0°。验收进入、保持、回正，测帽/头、躯干和宿主根的三组变换。星云 v2 的独立坐姿接分层头，可延续头绑定；魔女坐姿是整张画稿，保持端正。 |
| 坐下、睡觉、醒来 | 星眠和星云 v2 都采用独立坐姿画稿。将颈口对到站姿头部连接点，用凳脚或实际支撑点对地，不让站姿腿播放下坐动作。按半蹲或双腿角度硬拼会改比例和裙褶。醒来前半程保持坐姿，检查坐、睡、醒、站四段。 |

## 6. 星云 v2 拎起、甩动和回落

星眠提供经验证的抓取、弹性摆动与释放动作。星云 v2 复用它的**惯性算法和弹簧参数**，按星云母版重新量臂长、髋和发根。直接用统一正弦角度转全身，会出现木板式晃动；两肩角度相同也不会自动让双手齐高。

以后遇到和星云 v2 同结构、同宿主的角色，直接从确认版的动作代码开始。移植保留输入信号、状态交接和各弹簧的行为，新测颈点、掌心、肩髋、发根和遮挡。若新角色素材结构不同，记录具体映射方式，再按同样的光标轨迹验证视觉和模型姿势。以前的魔女只证明抓放事件会发生，未验证惯性，不能据此判定晃动合格。

1. 接官方宿主的 `pointer` 抓起和放下、`frame.mode`、`swing`、`tilt` 和朝向。只有抓取及其空中余摆接管整体旋转。肩、颈、发束和呆毛分别有目标与阻尼。根坐标以拎住的位置为轴，对宿主拎起的横向缩放、纵向拉伸做反向补偿，防止原 Q 版比例被拉坏。
2. 复用二阶弹簧的半隐式步进 `v += ((target-x)*k-v*c)*dt; x += v*dt`，上限之外夹紧并清速度。已采用的例值为头 `(70,10,16)`、发横摆 `(55,7,1.8)`、呆毛 `(140,6,38)`、近臂 `(60,9,125)` 与远臂 `(60,9,95)`，依次是刚度、阻尼、输出上限。让发束跟随颈角速度和拖动速度，腿从固定髋根渐增形变，近远腿交替摆。移植时按比例、锚点和运行时 `dt` 复测。
3. 为每只手量掌心和自己的肩点。用旋转圆弧由目标高度反解两只肩角，选正确方向分支。星云 v2 原位掌心约 `(465.7,904.5)`、`(827,898.5)`，用母版共同目标高度 `863 - 14*sin(t*13)`，弹簧后再用两掌的平均投影高度约束齐高。两只手明显低于肩线，角色整体侧倾时掌心连线随身体转。其他角色须重测，不能照抄这些坐标。
4. 星云 v2 使用匹配后的近远眼「＞＜」和小 ω 嘴。预览同时检查脸、比例、肩根不会穿披肩。验证从左右快拖到突然停住，再悬空、释放、着地、回待机。停止拖动后应有逐渐衰减的惯性；验证 `grab`、`drop` 和 `land` 或实际宿主对应事件，并确认回落后恢复表情与手位。

## 7. 尾巴、配重与连续小动作

- 星云 v2 摇尾借用鲸鱼娘的尾根旋转、尾尖二次弯曲及弹簧 `(40,5,32)`。使用连续相位，改变节奏时保留上一帧相位，平滑进入和恢复。调到约 0.85 倍节奏、0.78 倍总角幅。站姿专用 `wag` 约 2.6 秒，开心、喜欢、期待也触发；坐姿和睡觉尾巴静止。检查尾巴与披肩、裙侧、腿交叠的正反极值。
- 前发、腰饰、耳尖和呆毛按独立物理属性做小幅运动，根部刚性、远端柔性。头部三轴组合、快速改向和回正一起看，两块共用的轮廓线需同一父变换或共享变形网格。用户已手修且通过的原件与锚点作为回退基线。

## 8. 预览、工程交接和正式交付

1. 用**实际会加载**的宿主预览。导入路径分清 `parts/` 可编辑原位素材、运行时裁图、`model.json` 或 `parts.json` 布局、图集格框和版本。一次热更新只读同一批稳定资源；写入不全保留上一有效版本并显示错误。记录 URL、清单路径和错误信息，换过图用实际核对证明热生效。
2. 检查零位叠图、局部放大和正常尺寸，再查深浅底、两种朝向、动作极值和连续过渡。分三层记结果：编译与文件验收、浏览器/真实宿主事件、原生 Coopanion 安装及用户审核。静态通过不能替代动态；“状态变成走路”不能替代看四肢。看到新错误先复现，再截图、量坐标或写断言；让旧稿失败、修订稿通过。用可视化复核数值之外的画风和空间关系。
3. 手工修改前给用户可编辑目录和热更新入口。保存母版、源 PNG、提示词、生成供体、变换、版本、上下游许可、环境和验收证据。只在得到正式打包指令后出导入包；工程交接 ZIP 与运行 ZIP 区分。清单 `id` 稳定，每个公开词条有有效时长，`about` 及中文/英文词条把实际外形、动作、交互和姿势讲清楚，供环境提示读取。ZIP 根是导入所需清单和它引用的资源。底图、无效生成件与日志不进入运行 ZIP。
4. 从干净解压目录用锁定依赖重建。星云 v2 0.1.9 的交接验证比对 29 个发布文件的字节，ZIP 外部时间戳可不同；魔女的打包脚本固定顺序和元数据，同环境可比对整个 ZIP 哈希。新运行包用新版本名，以便回退已经验收的包。仓库首页应直接链接跨角色规范、角色实例与能复用的工具。
