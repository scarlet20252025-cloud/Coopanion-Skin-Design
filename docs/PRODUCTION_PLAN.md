# 绘制工程

## 目标与决策

已确认：以用户参考制作 GPT 龙娘，使用最新 v005 银白浅紫原画作为唯一制作基准，参考 Coopanion 官方分件动画。角色名字、性格与最终美术验收尚未确定。当前版本和阶段以 production-lock.json、brief.json 为准。

建议第一版二头身或接近二头身，身体基本直立、朝右的轻微侧身，双眼可见；保留四肢与衣摆的可分离轮廓。具体造型由母版评审决定，不能把这些建议写成用户已确认的设定。

首版只做一个角色、一套服装、一套配色。重点是小尺寸可辨识、动作自然和可修订源文件，不以部件数、表情数或生成次数衡量完成度。

## 官方经验如何落地

官方鲸鱼娘以一张母版为核心，通过删除局部和补画遮挡区域产生部件，再配准回母版坐标。可见部分尽量保留母版像素；配色共享几何，表情尽量复用五官层。我们沿用这一原则，将自动分层加入前置小样，而非一次就押注整条新流程。依据见 [SOURCES.md](SOURCES.md)。

Coopanion 的 kit 提供行为与状态；rig 是分件网格渲染工具，具有类似 Live2D 的变形能力，但并不等同于 Cubism 文件加载器。现阶段优先直接输出 Coopanion 形象包。

## 阶段与停止条件

| 阶段 | 具体工作 | 产物 | 进入下一阶段的条件 |
| --- | --- | --- | --- |
| P0 设定 | 明确轮廓、配色、服装、辨识点；最多先比较 2–3 个方向 | brief.json、参考索引 | 选定一个方向；分清固定项和可改项 |
| P1 母版 | 画一个全身中立姿态，检查缩小后的脸和配件 | master-v001.png、生成提示词 | 原尺寸及拟用桌面尺寸可读；无裁切；比例与方向锁定 |
| P2 分层试验 | 同一母版尝试 See-Through；检查眼睛、头发、手臂和遮挡补全 | 分层 PSD、部件检查表 | 中立姿态合成保持身份与轮廓；能独立移动关键部件 |
| P3 拆件精修 | 按缺陷局部补画，修边、补眼白和虹膜，记录锚点和层序 | KRA/PSD、透明 PNG、parts.csv | 轻微转头、抬臂、摆腿时无明显洞口和接缝 |
| P4 最小动画 | 待机呼吸、眨眼、视线、说话、走路、招手、拖拽释放 | 开发预览、figure 适配层 | 原生 kit 驱动下效果稳定；点击区与身体位置一致 |
| P5 扩展 | 坐姿下半身、睡眠与开心/惊讶，再加配色 | 新部件、表情、配色映射 | 基础动作回看通过；配色不改变几何 |
| P6 发布 | 缩略图、manifest、打包、真实应用导入 | figure.json 包、验收记录 | Coopanion 导入及重启后正常；词表、透明度、换色和缺件错误检查通过 |

建议投入权重：设定与母版 25%，分层与修补 35%，动画适配 25%，验收 15%。这是排期建议，不是生成耗时或成功率承诺。P2 完成后按实际返工数据估算剩余工作。

## 几何与分层契约

- kit 绘制的逻辑身体区域为 256×256，水平基准 x=128，脚底 y=256。它是逻辑坐标，不是强制原画只能 256 像素。
- 建议制作母版先用 1024×1024 RGBA，部件在高分辨率源坐标中保留位置，导出时统一映射到逻辑坐标。母版不必铺满画布；脚底和视线锚点另行记录。
- 若部件裁边，必须同时保存 crop offset；禁止逐部件居中或各自缩放，否则原位合成与骨架都会错位。
- `parts.csv` 记录自己的 near/far ID，与 PSD2Live 的角色自身 left/right 通过显式字段映射。侧身朝向未冻结前不猜两者对应关系。
- 第一批身体层：后发、脸底、前发、上身、下装、近/远手臂、近/远腿。五官按眼白、虹膜、上睫毛、眉、张/闭嘴拆分；配件按是否需要独立摆动决定是否拆层。
- 坐姿下半身属于后续专门差分，不强迫站姿裙腿拉伸成坐姿。衣服边缘留遮挡余量，具体宽度以最大动作试摆为准。
- PSD 交换文件按 RGB/8 位、透明背景和栅格图层准备；KRA 作为可编辑绘制主文件时，导出 PSD 后重新检查层序与混合效果。

## 自动分层与 Live2D 支线

See-Through 官方提供单图语义分层与遮挡补全。自动分层只产生候选源文件，不能代替关节检查。先对一张母版做一次完整试验，记录分层等待时间、人工修补时间和合格部件比例。

若脸型、发型或轮廓明显漂移：停止整图反复分层，保留可用层，转为官方局部编辑方式。配准使用未编辑区域作为依据；优先简单平移/相似变换，必要时才用 ECC 仿射，避免把真实造型差异硬扭成一致。保存变换矩阵、叠图和残差；官方个案约 1 像素的残差不作为所有素材的保证。

Auto_Vtb / PSD2Live 可用于同一份 PSD 的自动绑定与物理试验。它们的嘴部输入要求、左右标记和图层标签应提前映射，避免重画素材。上衣、裙摆、腿部与头发物理值得借鉴；不因工具默认支持某种物理就自动加入角色设计。

PSD2Live 的 `.moc3` / `.model3.json`、`.p2lrt` 等输出需要各自运行时。若以后采用这些运行时，先验证离线资源加载、Coopanion 沙箱兼容、frame 参数映射和命中区域，再决定是否换主线路。当前不把其自动绑定产物宣称为可直接导入 Coopanion。

## 最少返工规则

1. 修改前读取 jobs.csv：同一母版、同一部件、同一目标若已有合格产物，直接复用。
2. 一次只改一个可验收目标。生成前写明不变项，完成后立即原位叠图与小尺寸查看。
3. 同一缺陷连续两次未改善，改用遮罩更小的局部编辑、人工修层或替代分件方案。
4. 冻结母版后，补画沿用该母版；不把一连串未经验收的生成结果继续作为下一轮基底。
5. 换色复用层和骨架，换装优先复用脸、头发、手足；坐姿等必要差分单独生成。
6. 只重跑受到修改影响的步骤。源图、遮罩、提示词、参数及工具版本确定后可用哈希作缓存键；第一版先用记录表，不提前搭调度系统。

## 验收分开记录

美术：轮廓、身份、配色、小尺寸可读性、深浅背景边缘。静态资产：透明通道、尺寸、crop offset、路径、锚点和层序。动作：闭眼不夹碎虹膜、张嘴不拉扯脸、步态不滑脚、接缝不露底。应用：导入、命中、拖拽、词表、切换与重启。四类各自记录，不能用静态检查通过代替桌面验收。
