# 已验收案例与工具

[通用手册](桌宠工程通用手册.md)写可迁移的判断和验收条件。[黑金魔女制作与复现手册](制作与复现手册.md)提供从实际供体到成品的完整可运行示例。本页的 `cases/` 来自以前验收过的工程，用来读取实现、对照参数和移植思路。它们依赖各自的画稿、模型和宿主，读取时保留原版本语境。当前预览、重建和出包统一从[仓库首页](../README.md)执行。

## 按任务找入口

| 要做的事 | 工具、代码和判断 |
| --- | --- |
| 生图补件 | 内置 ImageGen，真实输入职责和提示词见当前 `work/`、`masters/生成提示词.md`、星云新版提示词归档。先拆参考，再生成补件和露出的底画。记录实际输出尺寸、模式、批准的素材。 |
| 对位、混色、裁边和叠回 | Pillow 处理 RGBA 拼合、重采样与裁图，NumPy 向量化遮罩/坐标，OpenCV 做仿射、特征配准和边缘修复。当前 `assemble_left_arm.py`、`assemble.py`、`review_parts.py` 均可执行。星眠当时的[配准工具](cases/xingmian/register_03.py)用完整画布上的稳定区做粗配与精配，参数应按新角色重测。 |
| 独立坐姿与脸型 | 星云 v2 的[独立坐姿工具](cases/xingyun-v2/prepare_sit.py)将身体、弯腿和凳位对上继续使用的头部；[脸底配准](cases/xingyun-v2/face_registration.py)仅生成编译用副本。当前魔女坐姿采用整张画稿，见 `assemble.py`。 |
| 眨眼、表情与色差 | 当前 `repair_eye_art.py`、`matched_blink.py`、`assemble_expressions.py`、`review_portraits.py` 有整脸画稿、固定取样调色、17 帧眨眼、单眨和说话回归。星云 v2 的眼嘴图集和眉形做法适合有足够脸内余量的角色。 |
| 拎起、倾听、跑步、摆尾 | 在[星云 v2 入口](cases/xingyun-v2/figure.js)找 `xingmianSpring`、`palmArc`、`viewAngles`、`heldLeg`、`runningStep`、`WHALE_WAG`、`groupTilt`。在[运行回归](cases/xingyun-v2/check_reactions.mjs)核对实际宿主入口、坐姿遮罩、掌心和尾巴。 |
| 静态和真实速度回归 | Node.js 本地服务与 Edge CDP。当前 `qa_preview.mjs` 检测实际 Canvas 渲染的表情格、倾听头身变换、拎放事件、双朝向对侧步相及鞋底着地。星云 v2 的[运动重组检查](cases/xingyun-v2/check_motion.py)和[头层检查](cases/xingyun-v2/check_head.py)带有可重用的对照逻辑。补增断言时用故障版本重放验证它能抓住旧问题。 |
| 打包和审查 | 使用锁定的 Python/Pillow/OpenCV/NumPy 版本；`package_project.py` 验证母版镜像、图集、编辑层与运行裁图，再写 ZIP 和 SHA-256。星云 v2 保留原 [handoff 工具](cases/xingyun-v2/handoff.py) 供其完整归档复现。 |

复用官方行为、特效和示例代码时保留版本和许可。当前工程内附[官方快照说明](../vendor/Coopanion-web/SOURCE.txt)和[许可](../vendor/Coopanion-web/LICENSE)。先选已知版本作基准，再移植动作响应，分别保存母版、供体、配准和最终渲染测试。
