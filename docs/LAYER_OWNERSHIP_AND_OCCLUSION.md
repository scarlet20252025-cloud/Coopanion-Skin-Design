# 分件归属、遮挡补全与残留验收

## 为什么反复出现残边、虚影和空洞

2026-10-13 的本地 r18 检查发现：站姿 `head-open` 在旧翅膀轮廓处被挖空；`wing-underpaint` 则由另一张无翼补画限制到旧翅膀 alpha 得到。运行时前者跟随头发网格和头部运动，后者留在翅膀组中。边缘的像素来源、裁剪轮廓、变换归属并不一致。静止时被翅膀盖住的断线，移动后会暴露。

这并不意味着补画的每个可见像素都属于头发。无翼完整图同时含袖子、身体和尾巴，把整张图或宽泛区域塞到后面，会重新引入重复身体、尾巴遮挡及虚影。此前扩张补片、只调层序的修正没有解决部件归属问题。

先区分四类原因：源素材混入邻接部件；移除前景后缺少真实后景；同一接缝两边使用不同变换；裁剪与抗锯齿边界不一致。不能把四类问题都当成透明缝去扩边。

## 部位关系必须明确

|部件|所有权与变换|需要保持的遮挡关系|
|---|---|---|
|翅膀|只含翼膜、翼骨和根部；绕翼根活动|翅膀在后发前，手臂是否在前按姿势确定|
|后发及遮挡补全|同一连续头发来源、同一头发变形；补全不属于翅膀|不得夹带袖子、手、衣裙、尾巴，也不得用补片覆盖它们|
|前侧发束|单独判定在肩和手臂前后的部分|不能把整片长发一律提到前景|
|肩、袖、手|保持关节连续；遮挡裁剪固定在遮挡物坐标|肩部连接不能当作穿身区域一起删掉|
|尾巴|独立源与尾根运动|先明确与发尾、裙摆的交叉关系，禁止用整片补画压住尾巴|

## 修改前的强制检查

1. 校验锁定母版及输入文件哈希。版本号、预览标题不能证明贴图来源正确。
2. 对问题区制作图层来源对照：原画、独立翼、头发、遮挡补全、合成结果。分件图必须标明“诊断分件”，不能当成完整头像展示或生成输入。
3. 隐藏前景翅膀，检查后发是否连续；再隐藏后发，检查独立翼是否带着头发边线。定位具体污染源之后再编辑。
4. 为每段边界写清像素归属、共享遮罩、关节及变换父节点。后发的补全必须与后发一起运动，不能留在翅膀组。
5. 任何补画都必须限制到语义正确的部位。几何扩大遮罩只能处理已确认的抗锯齿边缘，不能作为缺失内容的修复方法。

## 验收要求

- 同时查看完整角色及问题区放大图，包含浅、深背景。
- 采样静止、振翅正负极值、头发反向摆动、招手、跑停、站坐切换与坐姿振翅；左右朝向都要核对。
- 分别检查旧轮廓残留、双线、半透明重影、透明洞、错误遮挡和肩部连接。不能只看一帧“更好看”。
- 原位像素一致、DOM 层序、无脚本错误、宿主 tick 回执，都不能替代上述视觉检查。
- 表情小修不应触发重新生成整个人物；只改嘴型应保留眼睛、身体和动作基线。笑嘴在缩小后也要检查，深色张口加舌头可能在桌宠尺寸下变成不自然色块。
- 同一问题连续两次未改善，应停止叠加补丁，回到源素材归属检查。未经视觉验收的候选不得覆盖当前安装版本。
