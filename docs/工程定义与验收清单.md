# Coopanion 桌宠工程定义与验收清单

这份文件定义从需求确认到交接的完整工程。当前可运行实例是黑金魔女 **0.1.2**。操作细节见[制作与复现手册](制作与复现手册.md)，历史上已经验收、可迁移的做法见[通用手册](桌宠工程通用手册.md)和[案例代码与工具索引](案例代码与工具索引.md)。新角色继承工作方法与验收标准，重新确定自己的母版、比例、层序、坐标和锚点。

## 阶段、交付与放行条件

| 阶段 | 输入与工作 | 应留下的产物 | 放行条件 |
| --- | --- | --- | --- |
| 1. 需求与选稿 | 记录角色识别特征、参考图各自的作用、四分之三朝向、比例、默认表情、姿势、道具、拟做动作和用户已完成的拆件。区分参考材料、用户要求和已选定素材。 | 候选提示词、用户确认的原图、工作母版及哈希。当前在 [masters](../masters) 和 [source](../source)。 | 朝向、角色比例和道具经确认。没有确认的候选不覆盖已选母版。 |
| 2. 拆件设计 | 以工作母版标画布、画面左右、前后遮挡、保护区、补画区、接缝与关节。分别画出移走部件后露出的底层。 | [锚点与层序](制作与复现手册.md#1-锁定母版和目标动作)、原坐标编辑图、遮挡关系、补画任务。 | 能说清每一片像素归哪层、会在哪个姿势露出。已有合格腿、尾巴、手修脸等素材优先沿用。 |
| 3. 拆件、再生成、修复 | 先拆可见参考，再用图像模型补全隐藏结构和后方底画。保存实际送入的图与提示词、原生成输出。局部配准、修边、恢复原坐标。 | [实际提示词与生成供体](../work)、[原坐标透明素材](../parts)、[遮挡蒙版](../masks)、[配准记录](../review/eye-registration.json)。 | 抠出的残片经过实际补画修复才能进成品。原比例、画风、手脚轮廓和已确认局部须回对母版。 |
| 4. 装配与绑定 | 明确部件归属、父变换和深度。运行时允许从整件源画生成前后绘制层，编辑源保持整件。绑定后逐个给活动件做极值。 | [模型与锚点](../pack/star-witch/model.json)、运行时贴图、[全身叠回](../review/standing-reassembled.png)、[动作极限](../review/full-motion-check.jpg)、[裙底层序前后对照](../review/skirt-leg-depth.jpg)。 | 原位对照和动态都检查。肩根、髋、发根、脸缘、衣摆在目标幅度内不断开、不穿层。 |
| 5. 表情与动作 | 以确认过的角色和官方宿主动作入口为依据，做匹配的五官画稿、过渡、独立坐姿、步态、头部视差、倾听、拎起、眩晕与特效。按角色需要加入尾巴、耳朵、呆毛或动物。 | [运行入口](../pack/star-witch/figure.js)、[图集与资源清单](../pack/star-witch/model.json)、[形象描述和动作词表](../pack/star-witch/figure.json)、[环境提示词](环境提示词.md)。 | 点击按钮后要查真实画面与状态顺序，进入、持续、退出都成立。沿用旧动作时直接从验收过的代码移植，并重新量本角色锚点。 |
| 6. 预览与用户验收 | 打开实际宿主预览，浅底、深底、桌宠常用尺寸与放大都有对照。手修用全幅原位 PNG，检查保存后实际热加载。重复失败回到母版、源画、层序和编译路径定位。 | [浏览器回归](../review/preview-qa.json)、[表情验证](../review/portrait-qa.json)、对照图、手修反馈和验收指令。 | 区分按钮触发、实际画面、用户验收和原生客户端验收。修好旧缺陷后还要回归一遍同区域的原有状态。 |
| 7. 打包和交接 | 用户明确要求出包时更新版号。生成安装 ZIP、工程 ZIP 和 SHA-256。空目录重建，从实际安装包再加载裁切贴图并复验。提交源画、约定、说明、工具、运行时和本版证据，核对远端树。 | 安装 ZIP、工程 ZIP、校验文件、Git 提交、[依赖锁](../requirements.txt)和[上游许可](../LICENSE)。 | 归档能从冻结的供体完整重建。当前环境验证可逐字节复刻。保留旧发布版以便回退；后续预览修订等待下一次明确打包指令。 |

## 用户已定下的执行要求

| 需要守住的要求 | 验证方式 |
| --- | --- |
| **先拆再用生图补全。** 直接抠出的残片只用于引导。既补活动件被挡住的上臂、膝、发根、杖杆，也补拿走部件会露出的披肩内衬、衣服或头皮。 | 保存引导、供体、修复层和原坐标叠回图；用目标动作看藏着的端部。 |
| **原坐标、轮廓与画风锁定。** 保护已经验收的手、腿、尾巴和用户手稿。手臂保持真实比例、肩肘腕轴和可抓住物体的手形。金属护肩按角色要求跟手臂。 | 叠回时量哨点与轮廓；运动时同时看大小、错位、断面和母版颜色。 |
| **裁图不改变前后关系。** 披肩和裙摆归身体源，披肩遮手臂根；后裙在腿后，前裙褶覆腿根。前发盖住眼，长发按锁定构图压对应衣饰，尾巴在规定区域压披肩。 | 查看单姿和运动极限，分别清点渲染顺序、遮挡区域及底层完整性。最下层后裙换深度；避免裁掉原衣裙。 |
| **表情逐套配准。** 用绘制的眼、嘴和动态眉或整脸画稿。拒绝硬切睁闭、挡刘海、眼周肤色圈、双眼皮残影、嘴边贴片接缝和肿下巴。色差先测同坐标肤色再修默认脸。 | 看原画与中间帧，播放状态切换；检查发边、脸缘、腮红、下颌与动作回默认。视差只在局部五官移动。 |
| **有通过的动作直接沿用。** 星眠、星云 v2 的挂起弹簧与状态交接按代码移植。拎起手低且齐，拖停有反摆并衰减；跑步收臂；走路对侧手脚同向，肢体速度独立于显示器横移；倾听只动头。 | 按相同操作轨迹验左右方向、手脚矩阵、拖停衰减、落地以及躯干是否参与倾听。 |
| **坐、睡与眩晕按进入顺序。** 坐下用独立画稿。眩晕圈眼与星星在坐姿首次出现时同步；凳脚保持稳定，闭眼摇头后回正。已有坐姿静尾要求继续生效；站姿尾巴可以随开心等情绪摆动。 | 采样首次绘制、峰值与恢复，另验站姿、坐姿和端部状态。 |
| **预览、验收、发布分开。** 用户手改先确保热生效，动作方案与画风校验完成后按明确指令出包。仓库同步现行工程、用户规则、案例、提示词与工具。 | 从两个 ZIP 重建和试跑，核对远端；任何未完成的客户端、DPI 或跨屏验证保持可见。 |

## 当前文件与验证状态

- 入口与规则为 [README](../README.md) 和 [AGENTS](../AGENTS.md)。环境提示的机器字段在 `figure.json`，中英文人工交接写在[环境提示词](环境提示词.md)。官方宿主快照、许可及来源随工程提供。
- 当前完整案例包括确认母版、实际供体、脚本与最终画稿。星眠及星云按[案例索引](案例代码与工具索引.md)保存适用的实现与经验，旧角色完整工程包单独存档。
- [清单检查](../package_project.py)支持 `python -X utf8 package_project.py --check`。用它检查归档输入、母版、运行贴图尺寸、编辑层一致性和本地文档链接。普通打包也先过同一检查。
- **0.1.2 验收范围**包含从工程 ZIP 在 Windows 空目录重建并比较两个 ZIP 的 SHA-256，以及从解压的安装 ZIP 运行实际裁切贴图的浏览器回归。Coopanion 原生客户端导入、多显示器与 DPI 仍待实测。重新出包先重新跑本版验收。
