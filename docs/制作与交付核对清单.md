| 其它星眠表情 | 平静、大哭、睡觉、慌张、得意、思考、期待、坚定、嘟嘴、害怕、担心 | 平静和睡觉有实际状态、画面或宿主入口，未列入这版的公开表情词条。其余作为后续可选需求，当前说明不把它们列入交付范围。 |

## 二、开工与素材生产

- [ ] 确认角色识别特征、画风比例、四分之三视角、默认表情和道具；引用材料各自的用途写清。把动作、表情、特效、装扮与宿主事件逐项定为交付、待定或不适用。
- [ ] 冻结母版及已验收的手修文件，记哈希、尺寸、朝向、画面左右、舞台单位、颈肩髋、发根、足底及道具关键锚点。用户手修版本就是下一版的输入，先防止旧编译覆盖它。
- [ ] 给每个部件记可见区、遮挡区、保护区、父层、前后层、位移和验收姿势。先拆可见参考再生图补全活动件和露出的底层，保留引导图、真实提示词、供体、变换与复核证据。
- [ ] 导出全幅原位 RGBA，验证尺寸、轮廓、透明边、色相和修复接缝。静态叠回母版，再测正负极值。披肩盖住肩根，护肩依角色跟随胳膊，后裙在小腿后，前褶仍盖腿根，头发、扣子、尾巴按母版约定前后。
- [ ] 需要时做独立坐姿和小凳。参考对比姿势的身体比例与手脚着点。确认凳子只在指定状态显示、承重落地、站姿腿隐藏。星眠改良后的坐姿逻辑同时覆盖睡眠、眩晕和醒来，跳跃与落地时回归防止误切坐姿。

## 三、表情、动作和交互验收

- [ ] 待机、正脸、睁眼、半闭、全闭、回睁、远侧单眨与说话各有明确入口或实际宿主触发。看过渡与连续播放，检查遮挡、双睑残影、嘴型方向、色跳和回待机。
- [ ] 每项交付表情都登记眼、口、眉对应的画稿或有意复用的状态。眼睛靠脸缘时用匹配的整脸画稿，五官保留异色瞳和透视。默认肤色和所有表情在相同取样区域对照。
- [ ] 站、走、跑、跳、落地、点头、摇头、鞠躬、坐、睡、醒逐项检查实际画面。走路双朝向验对侧摆臂、承重与停步，跑步验收臂，跳跃验腾空和落地，坐下验凳脚与站姿腿显隐。
- [ ] 两种朝向分别验倾听时头部独立歪动；转头、抬低头和指针跟随验近远眼和嘴的相对视差、刘海遮挡以及原下颌。复查开始、稳定、恢复，记录适用的坐姿与站姿范围。
- [ ] 左右快拖拎起，停住测回摆衰减和低位齐掌，松手见落地后恢复。眩晕核对第一帧坐姿和表情同时、双圈眼旋转、星星公转、下身稳定、闭眼回正、特效清理。
- [ ] 生气标、汗滴、惊叹、问号、泪滴、睡眠符号、爱心等按交付范围逐个触发检查。适用的尾巴、耳朵、呆毛、配饰、发束要查根部、惯性、遮挡和坐睡显隐。
- [ ] 点按、摸头、快甩、跨屏、特殊手势、换装、配色、音效等按需求逐项标注。宿主默认状态、模型专用动作、外部预览按钮和向 AI 公开的词条分开登记。
- [ ] 深浅背景、正常尺寸和放大、两种方向、动作开始与收尾均看一轮。每次修 A 后复查共享图层或状态的 B。例如改坐姿条件时同时回查坐、睡、醒、眩晕、起跳与落地。

## 四、发布与交接

- [ ] 先预览和用户验收。明确得到打包指令才更新发布版。保存已通过版本、最终编辑源、运行贴图及变更记录。
- [ ] 核对清单的包标识、版本、清单/宿主 API、入口与导出、缩略图、作者、依赖和许可。环境提示词如实描述外形和实际动作。公开词条的 id 与各语言名称全局去重，并核对类型、非法分隔符、说明、正时长和代码支持。星眠曾因眩晕和转圈都用了「转圈」而导入失败。
- [ ] `axes`、`presets`、自带音效、独立缩略图如本角色采用，检查选项引用、颜色方案、服装落位与声音触发。安装包只带可运行所需资源，工程包附上原图、最终手修、可复现供体、提示词、工具、依赖、核对清单与证据。
- [ ] 跑文件完整性检查。空目录解压工程，重新编译并校验 ZIP；用安装包实际资源验证。另记原生客户端导入、真实 DPI 和多屏的验证状态。仓库同步源文件、交接文档和本版证据，远端核对后发用户可用的两个文件链接。
