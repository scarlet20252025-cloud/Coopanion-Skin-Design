# 定点素材编辑提示词

目标：只修改【部件/问题】，输出独立透明 PNG。

输入 A：当前已选定的完整角色，用于整体形体、方向、配色和线条。
输入 B：【问题区裁图/当前姿态】，裁图不是另一张母版。

保留：人物朝向、头身比、肩线、服装宽袖、光源、线条粗细、颜色与【其他固定项】。
允许改变：【具体动作/被遮挡区域/表情】。
隐藏结构：【谁移开后露出谁】，只补该对象；不带旧前景轮廓。
交付：【画布/透明度/部件】。不增加邻接耳朵、头发、袖子或裙子像素。

坐姿等大体态先要求完整人物设计，再分离身体；不要只给孤立身体和一个头部锚点让模型猜整体形体。

生成后记录逐字提示词、输入/输出文件、hash、来源和配准。画布/外形有漂移时先注册，再复核；生成工具的“已完成”不是美术验收。
