# 部件归属、配准和接缝

## 修图前画清四件事

对被圈出的每条边，写下：像素属于谁；运动由哪个父节点负责；谁遮谁；边缘来自原画、生成补底还是裁剪。它们决定修法。

| 症状 | 优先排查 | 合理动作 |
| --- | --- | --- |
| 原地就断开 | 注册矩阵、锚点、原始接合位置 | 以母版肩袖位置对齐，等比移动 |
| 只有抬手后裂开 | 补底是否混入旧袖子/发尾、遮罩坐标 | 分离语义源；遮挡边固定在遮挡物坐标 |
| 头发和手互压 | 耳朵与前发是否在同一片 | 独立耳层；耳后、臂中、前发前 |
| 深底才见暗带/残线 | alpha、重复混合、旧轮廓 | 比较来源和 alpha，复查预乘混合 |
| 新姿态被切掉 | 用了旧剪影强裁新源 | 新源自己的 alpha，重新核对归属 |
| 动态网格裂缝 | 同源相邻片边界抗锯齿 | 仅确认同源同运动后作有限重叠 |

禁止把这些不同问题统一处理成“扩大遮罩”。源图缺失和抗锯齿缝是两件事。

## 坐标与矩阵

龙娘原画画布是 1254 × 1254，近远侧命名采用**屏幕左右**。SVG/Canvas 的 `[a,b,c,d,e,f]` 表示：

```text
x' = a*x + c*y + e
y' = b*x + d*y + f
```

等比且不反射的必要检查：`a*c+b*d ≈ 0`、`hypot(a,b) ≈ hypot(c,d)`、`a*d-b*c > 0`。用容差，不能靠图片“看上去差不多”。双臂注册现为 0.67 等比，头部和衣裙有小角度等比注册；实际矩阵读取 `part-registration.json`。

修改注册后同时维护 `model.json.part_registration`。真实宿主 `connect-src` 禁止额外 JSON fetch，所以运行期读嵌入 model；不要只改外部 JSON 后以为安装版已更新。

先确定 ECC 的参考/目标与 `WARP_INVERSE_MAP` 方向，再做变换。相关系数高只说明选定区域对齐，不说明新肩部、肤色或隐藏轮廓正确。

## 接合的已验证方法

- **肩袖：** 双臂从一致源提取，比例固定，绕真实肩点旋转；保留完整宽袖和手掌。袖口内部应有衣料内衬/被遮住的皮肤，不是透明空洞。不要为了“撑地”把手臂拉长。
- **颈部：** 母版连续皮肤与衣领共同取出；内衬仅保留裙下区域，避免两套领口叠加。接合两边共用身体变换。
- **裙腿：** 前裙片覆盖腿，内衬位于后；腿的可见范围从原坐姿/母版关系出发，不能前后裙片各裁一套不同边界。
- **耳与发：** 近耳与耳后侧发片分别独立，跟随同一头部 transform。招手手臂在耳朵和耳后侧发之前，脸侧发束在臂前；不要把整个头图抬到手臂前。
- **呆毛：** 从头部先清除旧呆毛和根尖，用匹配头顶素材作连续混合；独立呆毛自己的 alpha 绕根点运动。运行时旧多边形强裁曾留下三角缝。
- **刘海：** 当前保留连续 head-front；拆片边界曾横穿新眼睑和头发。没有匹配独立素材时，保留连续源比虚构补底准确。
- **翅膀：** 清晰分离翼与后发，翼根藏在身体背后；上扇能露出翼形，后发不能遮掉全部翼面。补发归属头发变形，而不是固定翼组。

## alpha 混合

局部替换若先 `destination-out` 扣旧图，再 `source-over` 贴一张同遮罩的新图，旧贡献会被重复衰减，产生半透明暗带。匹配的交叉混合应按预乘颜色 `old*(1-mask)+new*mask` 处理；当前 Canvas 用 destination-out + lighter 合并，再恢复 source-over。

羽化只平滑同一真实区域的颜色/alpha；不能把羽化当作画出隐藏结构的方法。眼周肤色硬边曾用 OpenCV 梯度域合成解决，区域外像素仍保持不变。
