# 动画与表情的修改入口

## 谁负责什么

官方 `preview/vendor/kit/body.js` 管行为、重力、拖拽、移动、状态与粒子；`packs/gpt-dragon-v005-r25/figure.js` 负责当前角色的像素、关节、姿态和覆盖关系。安装时使用宿主提供的 kit/loadImage/model；预览使用固定版本的本地 kit。

API 2 工厂接收 host 与 kit，返回 `step(dt)`、`layout()`、`do(word)`、`pointer(type,p)`、`drop(p)`、`place(x,facing)`、`set(...)`、`dispose()` 等方法。公开方法叫 **drop**，不是内部的 dropAt。调用动作后记录返回值；无错误但返回 false 不是成功。

## 当前角色约束

- 待机弹性 `idle_strength=0.7`、跳跃 `strength=0.65` 是用户已指定的龙娘参数，不是所有角色的通用值。
- 双臂 pivot 来自本角色，招手保留原宽袖与掌心差分。95° 抬臂、9° 摆幅、3 周是当前配置，不能作为另一角色的默认姿势。
- 普通坐姿 `seated-body-rebuilt`，晕乎 `seated-body-open-arms`；后一种保持原身体/裙腿，只让手臂自然向两侧垂下。旧鸭子坐、长臂撑地、独立新腿型已否定。
- 坐姿两层共享 0.8 等比 + [136,158] 平移、脚底 1120。晕乎恢复前锁定对应身体，直到坐姿混合结束，避免中间闪回另一身体。
- 当前刘海连续；脸侧发束只在下段施加小幅连续位移。呆毛独立旋转并接收短点击冲量，拖拽不应误触点击冲量。

## 表情

`expressions.js` 管眼状态、嘴、圈圈眼与贴图选择；`brows.js` 管独立眉毛。先清除源图固定眉毛，保留额头可见区域裁剪，再加新眉线。眉毛不能随眨眼消失，也不能画到刘海上。用户只要求对齐 dizzy 眉毛的对应高度，其余情绪不强行对称。

提起时用 flustered 挤眼差分；晕乎用淡紫圈圈眼、细紫螺旋、波浪嘴和官方星星/摇晃。晕乎抑制随机眨眼打断。表情参数平滑进入和退出，并复查半闭/全闭切换，避免虹膜滞留。

## 动作与粒子

`wings.js` 读取情绪、拖拽和官方映射信号。开心/期待约 3.2 Hz，提起约 4 Hz；连续相位与能量平滑进入/收势，避免切换时拍动方向跳变。尾巴用独立 tail.js，疏鳞纹要与头发、衣裙线条一致。

音符来自官方 kit 的 dance emitter 和 renderer，不在龙娘 `official-effects.js`。缺少某特效时先追踪 `do → state → anchors → particle → color`；不要立即重复画一套。汗滴按 `effect-policy.js` 只在指定紧张表情出现。

## 必测组合

```text
待机 → 点击 → 恢复
提起 → 保持 → 松手 → 落地 → 恢复
跑步 → 停步 → 招手 → 待机
坐下 → 开心/振翅 → 站起
晕乎 → 挤眼恢复 → 站起
左右朝向招手；深浅背景头部晃动；翼正负极值
```

单独启动各动作不能发现上一个动作残留。每次只扩展和当前改动相关的检查，已有充分通过证据后不无理由重复全量渲染。
