# ATRI 整件生成候选

Coopanion API 2，作者 Asryto。隔离候选，未安装、未发布，等待用户美术验收。

13张完整生成图层及26张保留表情贴图；不含母版身体余层、旧裁片遮罩、程序描线或发丝拼补。头发、双马尾与头部共用父变换，马尾和呆毛独立旋转；完整双袖按肩轴旋转，手仅露出母版小指尖。坐姿为独立完整绘画，保留原表情；坐姿长发目前随整张坐姿图，未拆成独立动态层。

抵消官方kit在呼吸、起身、落地阶段施加的非等比缩放；位置命中与视觉使用相同补偿。只对新组件机械清除游离alpha碎点，透明边缘RGB参照鲸鱼娘导出流程扩展，alpha和不透明绘画均保持。

实际输入、原始出图、逐件矩阵见SOURCE.json与工程characters/atri-01/official-regeneration。使用内置imagegen；无OpenArt、付费API或Adobe生成。
