# 星眠 · Coopanion 形象包预览版 0.1.0

**形象名称：** 星眠  
**形象 ID：** `star-sleep-01`  
**目标：** Coopanion figure pack API 2

## 当前完成范围

本版本以委托方提供的 1086×1448 透明立绘为唯一母版，原图完整保留为一个刚性图层。已接入 Coopanion 官方 kit 的整体移动行为，可作为导入和宿主兼容性的第一阶段预览。

当前没有独立的头部、手臂、腿、头发、眼睛或坐姿美术图层。因此本版本不宣称支持独立招手、眨眼、表情替换、自然坐姿和肢体摆动；对应素材应按母版坐标补绘后再增加动作。

## 安装

在 Coopanion「装扮 → 导入」中选择本 ZIP，之后选用「星眠」。ZIP 根目录直接包含 `figure.json`。

## 资源

- `tex/star-sleep.png`：完整透明原画，未进行局部裁切或改绘。
- `thumb.png`：装扮页缩略图。
- `model.json`：独立画布、脚底、中心线、边界、点击区、气泡锚点与图层契约。
- `SOURCE.json`：来源、SHA-256 与权利状态。

本版本为预览候选，不代表完整多层动画已经验收。
