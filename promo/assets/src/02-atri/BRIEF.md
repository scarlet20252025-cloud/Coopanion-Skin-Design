# 亚托利（ATRI）宣传片 · 制作要求

- 作者：Asryto
- 时长：**36 秒**，1920 × 1080，30 fps（1080 帧）
- 形象包：`packs/atri-v011`（v1.1.0，已验收发布版）
- 风格：深海蓝、银白、水下光柱；SVG 矢量背景、字幕、界面、指针与镜头；线性位移与淡入淡出。
- 配乐：`szak - 親愛なるあの日々へ`（第三方版权音乐，仅本机渲染使用，**不入库**）

## 与 GPT 龙娘那支的关系

同一套管线换主题后的升级版。共用的部分：

- 逐帧截图 → FFmpeg 编码 → 全片解码校验的三段式管线；
- `window.renderAt(t)` 单调时间驱动，角色逻辑 60 Hz 推进、画面 30 fps 采样；
- 只操作 `127.0.0.1` 的离线电影页，不驱动真实用户桌面。

这一版改进的地方：

| 维度 | GPT 龙娘（1.0.2） | 亚托利（本版） |
|---|---|---|
| 时长 | 30 s / 900 帧 | **36 s / 1080 帧** |
| 背景 | 深色渐变 + 点阵 | 三层视差光柱 + 34 个确定性上浮气泡 + 7 条漂移水波 + 径向光晕 + 暗角 |
| 场景转场 | 位移 + 透明度 | 位移 + `easeOut` 缓动，字幕逐条上浮 |
| 对话 | 单轮 | **三轮递进**，轮次有指示点，逐行出字 |
| 表情演示 | 招手/振翅/跳舞 | **八个 chip** + 专门的「叫她萝卜子→生气」桥段 |
| 配乐 | 104 BPM 钢琴感（原创合成） | 92→BGM 换为指定曲目，裁 36 s、1.2 s 淡入、2.5 s 淡出 |
| 角色构图 | 固定缩放 | 按场景变焦（对话 0.66、坐姿上移、片尾 0.94） |
| 动作校验 | 记录 accepted | 记录 accepted，**任一 false 直接中止渲染** |
| 指针交互 | 点击 + 提起 | 点击 + 提起，指针坐标跟随场景缩放联动 |

## 分镜（七段）

| 时间 | 画面 | 重点 |
| --- | --- | --- |
| 0–4 s | 亚托利挥手、眨眼出场，标题与横线展开 | 亚托利 / 海中来的高性能少女 |
| 4–13 s | 缩放到 0.66，**三轮对话**逐行出字 | 陪伴 → 撒娇 → 闹别扭 |
| 13–18.5 s | 指针点击呆毛，再提起放下 | 点击反应、提起挣扎 |
| 18.5–23.5 s | 八个 chip 依次点亮 | 招手/开心/跳舞/害羞/惊讶/嘟嘴/晕乎/生气 |
| **23.5–30 s** | **叫她「萝卜子」→ 惊讶 → 嘟嘴 → 生气** | 本片重点，红色光晕 + 抖动 + 青筋 |
| 30–33 s | 原坐姿切到圈圈眼 | 自然坐下，晕乎也有小情绪 |
| 33–36 s | 名称、作者、版本、安装指引 | Asryto，开放源码，导入即用 |

### 「萝卜子」桥段的时间轴细节

这是这一版最花心思的地方，情绪是三级递进，不是一下跳到生气：

| 时间 | 表情 | 台词 |
|---|---|---|
| 23.8 s | `neutral` 复位 | — |
| 24.4 s | `surprised` | 「……你刚才，叫我什么？」 |
| 25.9 s | `pout`（嘟嘴） | 同上，副行「（歪头，眉毛皱起来）」 |
| 27.4 s | `angry` + 青筋 + 红色光晕 + 抖动 | 「说了不是萝卜子！」/「我可是高性能的！」 |
| 28.6 s | `determined` + 重新开口 | 同上 |

右侧三步指示条（惊讶 / 嘟嘴 / 生气·青筋）同步点亮，观众能看清情绪是**一步步**上来的。

## 硬约束

- 不调用真实聊天模型；气泡文案是示例。
- 不展示个人配置、聊天记录或凭据。
- 角色为 `packs/atri-v011` 的原位图纹理与真实 kit 动画，不是重新绘制的纯矢量角色。矢量只负责背景、界面、字幕与指针。
- 每帧必须先有 `body.do(word)` 返回 true，画面里出现该动作才算数。
- 表情之间有 `busy()` 互斥：一次点击反应播放期间，再发表情会被 `kit/body.js` 拒收。所以动作脚本必须留足间隔。

## 素材归属
