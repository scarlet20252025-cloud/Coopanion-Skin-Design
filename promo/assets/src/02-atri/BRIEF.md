# 亚托利（ATRI）宣传片 · 制作要求

- 作者：Asryto
- 时长：**60 秒**，1920 × 1080，30 fps（1800 帧）
- 形象包：`packs/atri-v011`（v1.1.0，已验收发布版）
- 风格：深海蓝、银白、水下光柱；SVG 矢量背景、字幕、界面、指针与镜头；线性位移与淡入淡出。
- 配乐：`szak - 親愛なるあの日々へ`（第三方版权音乐，仅本机渲染使用，**不入库**）

## 节奏原则（2026-10-31 用户要求「放慢」）

用户原话：「演示的太急促了，放慢一点，篇幅长一点无所谓」。

据此定的硬规则，改时间轴时必须遵守：

| 规则 | 数值 |
|---|---|
| 单个表情展示时长 | **≥ 1.4 s** |
| 同段落内相邻动作间隔 | **≥ 1.4 s** |
| 「萝卜子」情绪递进每级 | **≥ 2.4 s** |
| 场景淡入 | 0.5 s |
| 场景位移 | 0.7 s（`easeOut`） |
| 气泡第一行出字 | 0.7 s |
| 气泡第二行延迟 | **1.3 s**（原来 0.55 s） |
| 出场横线伸展 | 1.4 s（原来 0.75 s） |

`kit/body.js` 的 `doWord()` 在 `busy()` 时拒收表情（点击反应播放期间），
所以间隔不只是观感问题，**间隔太密动作会被真的丢掉**。渲染器会记录 `accepted`，
任一为 `false` 直接中止，不会产出哑音视频。

## 分镜（七段 / 60 秒）

| 时间 | 画面 | 重点 |
| --- | --- | --- |
| 0–7 s | 挥手 → 注视 → 开心 → 眨眼，标题与横线慢慢展开 | 亚托利 / 海中来的高性能少女 |
| 7–22 s | 缩放到 0.66，**三轮对话**逐行出字（每轮 ~4.8 s） | 陪伴 → 撒娇 → 闹别扭 |
| 22–31 s | 指针点击呆毛，停顿，再提起放下（提起段 3 s） | 点击反应、提起挣扎 |
| 31–42 s | **六个 chip** 依次点亮，每个约 1.77 s | 招手/开心/跳舞/害羞/惊讶/晕乎 |
| **42–52 s** | **叫她「萝卜子」→ 惊讶 → 生气** | 本片重点，红色光晕 + 抖动 + 青筋 |
| 52–56 s | 原坐姿切到圈圈眼 | 自然坐下，晕乎也有小情绪 |
| 56–60 s | 名称、作者、版本、安装指引 | Asryto，开放源码，导入即用 |

### 表情段为什么只有六个

2026-10-31 用户要求删掉「蹭蹭」与「生气」两个演示：

- **蹭蹭**不是 `model.words` 里的可演示动作，硬放进去只是个标签，没有对应的真实动画；
- **生气**不在这一段落演示——它留给 42–52 s 的「叫她萝卜子」桥段专门推进。
  在那里它是剧情结果，比在 chip 里一闪而过有力得多。

删掉两个后，原本 6 个 1.4 s 的槽位摊到 10.6 秒里，每个约 **1.77 s**，节奏更松。

### 三轮对话

| 轮次 | 时间 | 标题 | 台词 |
|---|---|---|---|
| 1 | 7.6–12.4 | 她就在那儿。 | 「别担心，这点事情我一下就做完了。」「毕竟——我可是高性能的。」 |
| 2 | 13.0–17.8 | 也会撒娇。 | 「累了就靠一会儿嘛，我陪着你。」「……不过只准靠一小会儿哦。」 |
| 3 | 18.4–22.0 | 也会闹别扭。 | 「诶，你刚才嘀咕什么？」「……我好像听到一个很失礼的词。」 |

左下角三颗轮次指示点，当前轮高亮。第三轮是「萝卜子」桥段的引子。

### 「萝卜子」桥段的时间轴（42–52 s）

情绪是两级递进，不是一步跳到生气：

| 时间 | 表情 | 台词 / 画面 |
|---|---|---|
| 42.6 s | `neutral` 复位 | 气泡从 42.7 s 开始浮入 |
| 43.6 s | `surprised` | 「……你刚才，叫我什么？」 |
| 44.8 s | — | 副行出字：「（歪头，眉毛皱起来）」 |
| **46.2 s** | **`angry`** + 青筋 + 红色光晕 + 抖动 | 标题变「我才不是萝卜子！」，副标题「千万别叫她萝卜子，后果非常严重。」，台词「说了不是萝卜子！」「我可是高性能的！」 |
| 49.0 s | `determined` + 重新开口 | 同上 |

右侧**两步**指示条（惊讶 / 生气·青筋）同步点亮，观众能看清情绪是**一步步**上来的。
生气时蓝色光晕被红色压下去（46.1 s 起 1.2 s 渐入），整块内容 34 Hz 轻微抖动（46.2–50.0 s）。

> 2026-10-31 用户反馈：46 s 的嘟嘴在成片里**没有真的做出动作**，所以删掉了这一级演示。
> 删完 46.0–48.4 空出 2.4 秒，把生气爆发从 48.4 提前到 46.2 填上，节奏反而更紧。
> 现在的两级（惊讶 → 生气）都是确实会播出来的动作。

## 硬约束

- 不调用真实聊天模型；气泡文案是示例。
- 不展示个人配置、聊天记录或凭据。
- 角色为 `packs/atri-v011` 的原位图纹理与真实 kit 动画，不是重新绘制的纯矢量角色。矢量只负责背景、界面、字幕与指针。
- 每帧必须先有 `body.do(word)` 返回 true，画面里出现该动作才算数。
- 表情之间有 `busy()` 互斥，动作脚本必须留足间隔（见上方节奏原则）。

## 与 GPT 龙娘那支的关系

同一套管线换主题后的升级版。共用：逐帧截图 → FFmpeg 编码 → 全片解码校验；
`window.renderAt(t)` 单调时间驱动；只操作 `127.0.0.1` 的离线电影页。

| 维度 | GPT 龙娘（1.0.2） | 亚托利（本版） |
|---|---|---|
| 时长 | 30 s / 900 帧 | **60 s / 1800 帧** |
| 背景 | 深色渐变 + 点阵 | 三层视差光柱 + 34 个确定性气泡 + 7 条漂移水波 + 径向光晕 + 暗角 |
| 对话 | 单轮 | **三轮递进** + 轮次指示点 + 逐行出字 |
| 表情演示 | 招手/振翅/跳舞 | **六个 chip** + 专门的「萝卜子」桥段 |
| 配乐 | 104 BPM 钢琴感（原创合成） | 指定曲目，裁 60 s、2 s 淡入、3.5 s 淡出、loudnorm −20 LUFS |
| 角色构图 | 固定缩放 | 按场景变焦（对话 0.66、坐姿上移、片尾 0.94） |
| 动作校验 | 记录 accepted | 记录 accepted，**任一 false 直接中止** |
| 指针交互 | 点击 + 提起 | 点击 + 提起，坐标跟随场景缩放联动 |
