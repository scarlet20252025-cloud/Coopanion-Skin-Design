# 亚托利（ATRI）宣传片 · 制作要求

- 作者：Asryto
- 时长：30 秒，1920 × 1080，30 fps
- 形象包：`packs/atri-v011`（v1.1.0，已验收发布版）
- 风格：深海蓝、银白、水下光柱；SVG 矢量背景、字幕、界面、指针与镜头；线性位移与淡入淡出。

## 与 GPT 龙娘那支的关系

不是复制品，是**同一套管线换主题后的升级版**。共用的部分：

- 逐帧截图 → FFmpeg 编码 → 全片解码校验的三段式管线；
- `window.renderAt(t)` 单调时间驱动，角色逻辑 60 Hz 推进、画面 30 fps 采样；
- 只操作 `127.0.0.1` 的离线电影页，不驱动真实用户桌面。

这一版改进的地方：

| 维度 | GPT 龙娘（1.0.2） | 亚托利（本版） |
|---|---|---|
| 背景 | 深色渐变 + 点阵 | 三层视差光柱 + 34 个确定性上浮气泡 + 7 条漂移水波 + 径向光晕 + 暗角 |
| 场景转场 | 位移 + 透明度 | 位移 + `easeOut` 缓动，字幕逐条上浮 |
| 配乐 | 104 BPM 钢琴感 | 92 BPM 水下 A 大调五声，低频水压床 + 稀疏水铃点缀 |
| 角色构图 | 固定缩放 | 按场景变焦（对话缩到 0.66 给气泡让位、坐姿上移、片尾收） |
| 动作校验 | 记录 accepted | 记录 accepted，**任一 false 直接中止渲染**（不留哑音帧） |
| 指针交互 | 点击 + 提起 | 点击 + 提起，指针坐标跟随场景缩放联动 |

## 分镜

| 时间 | 画面 | 重点 |
| --- | --- | --- |
| 0–4 s | 亚托利挥手出场，标题与横线展开 | 亚托利 / 海中来的高性能少女 |
| 4–9 s | 缩放到 0.66，对话气泡逐行出现 | 桌面陪伴，"我可是高性能的" |
| 9–14 s | 指针点击呆毛，再提起放下 | 点击反应、提起挣扎 |
| 14–20 s | 招手 / 开心 / 跳舞 / 害羞 四个 chip 依次点亮 | 48 个标签，表情跟随动作 |
| 20–25 s | 原坐姿切到圈圈眼 | 自然坐下，晕乎也有小情绪 |
| 25–30 s | 名称、作者、版本、安装指引 | Asryto，开放源码，导入即用 |

## 硬约束

- 不调用真实聊天模型；气泡文案是示例。
- 不展示个人配置、聊天记录或凭据。
- 角色为 `packs/atri-v011` 的原位图纹理与真实 kit 动画，不是重新绘制的纯矢量角色。矢量只负责背景、界面、字幕与指针。
- 每帧必须先有 `body.do(word)` 返回 true，画面里出现该动作才算数。

## 素材归属

- 角色与特效：`packs/atri-v011`（见该包 `VERSION.md`、`SOURCE.json`、`LICENSE`）。
- 背景、界面、字幕、指针：本目录 `atri-film.html` 内的 SVG。
- 配乐：`generate-atri-audio.py` 原创合成，无第三方采样。
